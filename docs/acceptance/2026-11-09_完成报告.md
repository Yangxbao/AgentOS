## 5. 诚实声明

1. config_io 的工作区 root_path **原样导入**（同机迁移场景）；跨机器导入需用户手工改包内路径——导入时 `validate_root(must_exist=False)` 只校验路径合法性不校验目录存在，目录缺失在首次访问时报错（行为如实记录）。
2. FTS 混合检索的召回提升是经验性的（命中不足即补 LIKE），无量化指标；排序仍以 FTS rank 优先。
3. 岗位编辑 UI 的"主岗位"默认值取自当前 is_primary；首次勾选新岗位且无主岗时自动设为主岗——边界行为已在前端受控，后端 `_validate_positions` 兜底。
4. 嵌套审批/自动续跑/预算预扣等前两轮功能本轮回归全过，无退化。
5. 仍未实现：账号体系、真实外网、embedding 向量检索、岗位新建/编辑（组织设置已有）、config_io 的任务/审批历史导出（设计边界：导出=配置与资产，不含运行历史）。
