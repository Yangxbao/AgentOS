## 4. 关键发现：Mock marker 与真实 function calling 的语义差异（重要教训）

| 路径 | Mock 模型 | 真实模型 |
|---|---|---|
| 触发工具调用 | 指令里的 `[tool:...]` marker（MockAdapter 专用语法） | 原生 function calling（模型看 schema 自主决定） |
| marker 对真实模型 | — | **只是普通文本，模型会忽略并直接文本回复** |
| 实验指令写法 | 可以用 marker 精确控制调用 | 必须用自然语言描述任务 |

**影响**：M3-F 端到端验收场景（GitHub 教程）的 marker 语法只在 Mock 下有效；真实模型实验的指令必须是自然语言。这是 Mock 与 Real 的本质差异，已在报告与文档中记录（AI briefing 同步）。
