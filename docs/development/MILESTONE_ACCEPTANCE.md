## M1 验收（预告）
- 组织/员工/模型连接 CRUD 全部有 API + UI + 测试
- 员工-模型解耦实证：同一模型两个员工执行记录互不干扰；切换主备模型员工身份不变
- 组织图可编辑且与数据一致
- 导入导出往返无损

## M2 验收（预告）
- 状态机全路径覆盖测试（含暂停/恢复/取消/超预算）
- 审批中心：高危动作 100% 拦截，Agent 自批在 DB 约束层被拒绝（有测试）
- 并行任务无状态串扰

## M3–M6
M3：审查报告 6 要素 schema 校验 + 返工上限生效测试 + 绩效归因与 LiteLLM 费用对账误差 <5%
M4：会议由调度系统强制结束（超时/达决议）有测试，无无限循环
M5：断线恢复补传不丢不重；撤销授权后任务即刻失效
M6：第三方 Agent 经 A2A 接入的端到端用例
