## 1 项目摘要

星舟科技是一家商业航天初创公司，核心业务涵盖卫星在轨服务、火箭测运控与航天数据应用三大板块。本项目（一期）为星舟科技交付五页响应式企业官网，实现品牌展示、业务介绍与客户触达目标。

**项目范围**：首页、服务、关于我们、新闻动态、联系我们五个 HTML 页面，配套共享 CSS 样式与 JS 脚本，零外部依赖，可离线打开。

**品牌规范**：主色深空蓝 #0B2545，强调色星辉金 #D4AF37，全站禁用红/紫色调；风格专业、科技感、留白多。

**验收结果**：10/10 验收标准全部通过，11 个缺陷全部修复（修复率 100%）。
