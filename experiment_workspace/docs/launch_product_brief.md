# AgentOS 云端协作版 · 产品简介

> 编制：产品经理-方远 | 日期：2026-11-12 | 版本：v1.0
> 依据：`research/launch_benchmark.md`（竞品与市场分析 v1.0）

---

## 一、产品定位

**一句话定位**：AgentOS 云端协作版是面向中小团队的 **AI 数字员工管理平台**——让每个 Agent 拥有角色、职责与汇报关系，让团队在共享工作空间中编排、调度、审核 AI 协作流程。

**定位象限**：云端部署 × 多 Agent 协作（市场格局右下象限），区别于"个人聊天助手"（左上）和"本地编排工具"（左下）。

**核心差异**：从"人用 AI"升级为"人管 AI 团队"。竞品（Coze / Dify / FastGPT / GPTs / Crew.ai Cloud）均以"工具编排"或"单 Bot 共享"为原子单位；AgentOS 以"数字员工 + 组织架构 + 团队空间"为原子单位，非技术人员也能理解和管理 Agent 团队。

---

## 二、核心卖点（3 条）

### 卖点 1：角色化协作范式——"数字员工"而非"聊天机器人"

- 每个 Agent 具备**角色名、岗位职责、汇报关系**，可在组织架构视图中拖拽设定上下级。
- 上级 Agent 可审核下级产出后再提交，形成"搜集→起草→审核"端到端协作链。
- **用户感知**：不是在"配一个 Bot"，而是在"招一个虚拟员工"。

### 卖点 2：团队空间原生支持——从个人工具到团队资产

- Agent 配置、知识库、对话历史归属**团队空间**，成员按角色（管理员 / 编辑者 / 查看者）共享，离职不带走。
- 支持 SSO / OAuth 接入企业身份体系，操作审计日志可追溯。
- **用户感知**：企业采购放心——数据归组织，不归个人。

### 卖点 3：单机→云端无缝迁移——保护存量投资，激活种子用户

- 单机版用户通过 `agentos sync` 一键将本地 Agent 配置、知识库上传至云端，保留全部 Prompt、工具、记忆。
- 云端版 100% 向下兼容单机版配置格式，本地修改可双向同步，迁移后保留本地副本可回退。
- **用户感知**：已有单机版工作不白费，升级云端即获得团队协作能力。

## 三、目标场景

| 场景 | 目标客群 | 典型用例 | 价值主张 |
|------|----------|----------|----------|
| **中小企业流程自动化** | 50–500 人企业 | 合同审核 Agent 审阅条款 → 风险标注 Agent 标红 → 法务人工确认 | 替代 1–2 名重复岗人力，月省 5,000–15,000 元 |
| **外包项目交付提效** | 5–30 人项目制团队 | 代码审查 Agent 扫描 PR → 测试用例 Agent 生成用例 → 文档 Agent 输出交付文档 | 项目切换时 Agent 配置跨项目复用，知识不随人员流失 |
| **超级个体虚拟团队** | 1–3 人创业者 | 运营 Agent 排期内容 → 客服 Agent 应答询盘 → 数据 Agent 生成日报 | 一人管理"虚拟部门"，零雇佣成本覆盖多职能 |
| **强监管行业合规推理** | 金融 / 政务 / 军工 | 协作管理在云端，敏感数据推理路由至私有化模型（BYOE），数据不出域 | 满足数据主权要求，同时享受云端编排便利 |

## 四、定价策略建议

### 总体思路：**免费单机版引流 + 云端订阅变现**

| 层级 | 目标客群 | 定价模式 | 定价要点 |
|------|----------|----------|----------|
| **单机版**（已有） | 个人开发者 / 体验用户 | **免费** | 持续维护，不因云端版发布而废弃；作为最大流量入口 |
| **个人云端版** | 超级个体（1–3 人） | 免费额度 + 基础包月（¥49–99/月） | 每月赠送一定 Agent 调用量；超出按阶梯计费；单用户空间，无团队功能 |
| **团队版** | 中小企业 / 外包团队 | 按席位包月（¥199–399/席位/月）+ 超量阶梯价 | 含团队空间、SSO、审计日志、行业模板；首月 30 天全功能试用 |
| **企业版** | 强监管 / 大规模部署 | 私有化定制报价 | 含 BYOE 混合部署、专属模板定制、SLA 保障、专属客户成功经理 |

### 定价原则

1. **同档位不高于竞品 20%**（上线前完成 Coze / Dify / GPTs 定价对标）。
2. **预算可控优先**：中小企业偏好包月，避免纯按量计费导致"不敢用"。
3. **单机版→云端版升级路径清晰**：单机版用户首次同步至云端赠送 30 天团队版试用。
4. **首月转化**：团队版 30 天全功能试用，降低决策门槛。

## 五、首发功能边界（明确做什么 & 不做什么）

### ✅ 首发包含

| 功能域 | 首发范围 |
|--------|----------|
| **角色化 Agent 管理** | Agent 创建 / 角色设定 / 组织架构视图（拖拽设定汇报关系） |
| **多 Agent 协作编排** | 至少 1 个端到端场景完整可用（调研→起草→审核）；可视化工作流编辑器 |
| **团队空间** | 多租户架构；成员角色（管理员 / 编辑者 / 查看者）；Agent 与知识库归属团队 |
| **单机→云端迁移** | `agentos sync` CLI；配置格式 100% 兼容；双向同步；本地副本保留可回退 |
| **行业模板** | 首发 3 个模板包：法务合同审核、电商客服+运营、软件外包交付 |
| **身份与权限** | 邮箱注册 / 登录；团队邀请；基础 RBAC |
| **审计日志** | Agent 调用记录、成员操作记录（查看 / 导出） |
| **知识库** | 团队级知识库创建 / 上传文档 / 基础 RAG 检索 |

### ❌ 首发不包含（明确不做什么）

| 功能域 | 不做原因 | 计划时间 |
|--------|----------|----------|
| **SSO / OAuth 企业身份接入** | 首发客群以中小企业和外包团队为主，企业 SSO 需求可由团队版邀请制暂时替代 | v1.1（首发后 4–6 周） |
| **BYOE 混合部署** | 架构复杂度高，需与用户私有化环境联调；首发聚焦纯云端体验 | v1.2（首发后 8–12 周） |
| **社区模板市场（UGC）** | 首发模板由官方提供，社区贡献需审核机制与分成体系，暂不具备 | v1.3（首发后 12–16 周） |
| **Agent 间实时通信 / 事件驱动** | 首发协作以"顺序编排"为主，事件驱动架构需更成熟的调度引擎 | v2.0 规划 |
| **移动端原生 App** | 首发仅提供 Web 端（响应式适配移动端浏览），原生 App 投入产出比低 | 视用户反馈决定 |
| **多语言 / 国际化** | 首发仅中文界面与文档，国际化需翻译与本地化测试 | 视海外需求决定 |
| **计费系统精细度** | 首发采用包月为主，不提供按 token / 按次的实时账单明细页面 | v1.1 |

### 边界说明

- **"协作"底线**：首发版本至少保证 1 个端到端多 Agent 协作场景完整可用；若编排能力不足，宁可推迟发布也不降级为"多人共用单 Agent"。
- **"单机版承诺"**：单机版持续维护，云端版为可选升级，不存在强制迁移。
- **"模板底线"**：3 个行业模板包均需经种子客户验证后方可随首发上线，不以"即将上线"话术宣传。
