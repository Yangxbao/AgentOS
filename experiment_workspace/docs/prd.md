## 1 项目背景与目标

### 1.1 背景

星舟科技是一家**商业航天初创公司**，核心业务涵盖卫星服务、火箭测运控、航天数据应用三大板块。当前公司尚无线上品牌阵地，亟需建设官方网站以支撑品牌展示、业务介绍与客户触达。

### 1.2 目标

1. **品牌展示**：建立专业、科技感强的线上品牌形象，面向政企客户传递商业航天领域的技术实力与行业站位。
2. **业务触达**：清晰呈现三大业务板块，帮助潜在客户快速理解服务能力并发起咨询。
3. **信息发布**：提供新闻动态页面，支撑公司里程碑、行业活动等内容的持续发布。
4. **一期范围**：五页静态响应式站点，无后端、无外部依赖，可离线打开，为二期（CMS/交互）奠定基础。

## 2 信息架构

### 2.1 站点地图

```
首页（Home）
├─ 服务（Services）
├─ 关于我们（About）
├─ 新闻动态（News）
└─ 联系我们（Contact）
```

全站共享**统一顶部导航**与**统一页脚**。

## 3 功能需求

### 3.1 响应式布局

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F-01 | 移动端适配 | P0 | 320px–768px 单列布局，768px–1024px 双列，≥1024px 桌面多列；导航移动端折叠为汉堡菜单 |
| F-02 | 触控友好 | P0 | 按钮/链接最小点击区域 44×44px，表单输入框高度 ≥44px |
| F-03 | 流式排版 | P1 | 字号使用 clamp() 或响应式阶梯，避免移动端字号过小（正文 ≥14px） |

### 3.2 表单校验

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F-04 | 前端校验 | P0 | 姓名非空；邮箱格式（含 @ 与域名）；留言 ≥10 字；提交前逐字段校验，错误信息就近显示 |
| F-05 | 提交反馈 | P0 | 校验通过后显示"提交成功"提示，清空表单；一期无后端，前端模拟即可 |

### 3.3 性能与离线

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F-06 | 零外部依赖 | P0 | 不引用任何 CDN 资源（JS/CSS/字体/图片托管），所有资源内联或本地引用，确保断网可正常打开 |
| F-07 | 首屏性能 | P1 | LCP ≤2.5s（模拟本地打开）；图片使用 WebP/AVIF 或 SVG；CSS/JS 内联或压缩 |
| F-08 | 语义化 HTML | P1 | 使用 header/nav/main/section/article/footer 等语义标签，提升可访问性与 SEO |

### 3.4 导航与页脚

| 编号 | 需求 | 优先级 | 说明 |
|------|------|--------|------|
| F-09 | 统一导航 | P0 | 五页共享顶部导航栏：Logo + 五个页面入口，当前页高亮；移动端汉堡菜单展开/收起 |
| F-10 | 统一页脚 | P0 | 五页共享页脚：版权声明 © 星舟科技 + 备案号占位 + 快捷链接 + 联系方式摘要 |
| F-11 | 平滑滚动 | P2 | 页内锚点跳转使用 smooth scroll 行为 |

## 4 设计系统

### 4.1 色彩

| 用途 | 色值 | 名称 |
|------|------|------|
| 主色 | `#0B2545` | 深空蓝 |
| 强调色 | `#D4AF37` | 星辉金 |
| 背景白 | `#FFFFFF` | — |
| 浅灰背景 | `#F4F6F9` | — |
| 正文灰 | `#333333` | — |
| 辅助灰 | `#666666` | — |
| 边框灰 | `#E0E4E8` | — |

> **禁忌**：全站不得使用红色系（#FF0000 等）与紫色系（#800080 等）作为主色或强调色。

### 4.2 字体

- 标题：系统无衬线字体栈 `"PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`
- 正文：同上
- 数字/数据：等宽倾向 `"Roboto Mono", "SF Mono", monospace"`（本地回退即可，不外引）

### 4.3 间距与留白

- 基础单位 8px，模块间距 64px–80px（桌面），40px–48px（移动）
- **留白多**：各模块上下留白 ≥ 模块内间距，避免信息拥挤

### 4.4 圆角与阴影

- 卡片圆角 8px，按钮圆角 4px
- 卡片阴影 `0 2px 12px rgba(11,37,69,0.08)`

### 4.5 图标

- 使用内联 SVG 图标，风格线性/细线，与科技感调性一致

## 5 文案基调

| 维度 | 要求 |
|------|------|
| 整体风格 | 专业、科技感、克制、留白多 |
| 目标读者 | 政府机构、军工单位、大型企业（政企客户） |
| 语气 | 自信但不浮夸，数据驱动，强调"可靠""自主""全链路" |
| 禁忌 | 不使用口语化/网络用语；不使用"最""第一"等绝对化用语（合规） |
| 业务关键词 | 卫星服务、火箭测运控、航天数据应用、低轨星座、在轨运控、遥测、数据融合 |
| 英文使用 | 专有名词可保留英文（如 LEO、TT&C），其余中文优先 |

| NF-01 | 浏览器兼容 | Chrome 90+、Edge 90+、Safari 15+、Firefox 90+ |

## 7 验收标准

> 以下每条须可独立勾选通过/不通过。

| 编号 | 验收条目 | 通过标准 |
|------|----------|----------|
| AC-01 | 五页完整交付 | 首页/服务/关于我们/新闻动态/联系我们五个 HTML 文件均可正常打开，内容无空白占位（除明确标注预留位外） |
| AC-02 | 移动端不破版 | 在 375px/414px/768px/1024px/1440px 五个宽度下，所有页面布局无水平溢出、无文字截断、无元素重叠 |
| AC-03 | 统一导航与页脚 | 五页顶部导航一致且当前页高亮；五页页脚内容一致；移动端汉堡菜单可展开/收起 |
| AC-04 | 联系表单校验 | 姓名为空时提示必填；邮箱格式错误时提示；留言少于 10 字时提示；全部正确时提交后显示成功提示并清空 |
| AC-05 | 零外部依赖可离线打开 | 断网状态下双击 HTML 文件可正常渲染全部内容与样式，无控制台 404/ERR |
| AC-06 | 色彩合规 | 全站 CSS 中无红色系（HSL 色相 345°–15°）与紫色系（HSL 色相 270°–300°）作为主色/强调色；主色为 #0B2545，强调色为 #D4AF37 |
| AC-07 | 文案体现商业航天业务 | 全站文案包含"卫星服务""火箭测运控""数据应用"三大业务关键词，无与航天无关的通用模板文案 |
| AC-08 | 首屏性能 | 本地打开 LCP ≤2.5s（Chrome DevTools Performance 模拟 Fast 3G 限速） |
| AC-09 | 语义化与无障碍 | HTML 通过 W3C Validator 零 error；图片均有 alt；表单 input 均有对应 label；颜色对比度 ≥4.5:1 |
| AC-10 | 交付物完整 | 交付包含：全部页面文件 + CSS + JS + 图片资源 + 本 PRD + 设计系统说明 + 测试报告 + 交付报告 |

## 10 风险与约束

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 一期无后端，联系表单仅前端模拟 | 用户提交数据无法持久化 | 二期接入后端 API；一期在提交成功提示中注明"我们将尽快与您联系" |
| 图片资源需本地托管 | 增加包体积 | 优先使用 SVG 矢量图；位图压缩至 WebP；控制单图 ≤200KB |
| 无 CMS，新闻内容硬编码 | 运营无法自助更新 | 二期规划 CMS；一期新闻页预留数据结构，便于迁移 |
