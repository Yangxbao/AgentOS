# 贪吃蛇网页小游戏 — 需求规格说明书

> 版本：v1.0  
> 作者：产品经理-唐糖  
> 日期：2025-07-11

---

## 1. 目标用户

| 维度 | 描述 |
|------|------|
| 核心用户 | 6–35 岁休闲游戏玩家，习惯在浏览器中即开即玩 |
| 使用场景 | 课间/通勤/工间碎片时间消遣，单局 1–3 分钟 |
| 设备 | 桌面浏览器（Chrome / Edge / Firefox / Safari 最新2个主版本）及移动端浏览器（响应式适配） |
| 技术门槛 | 零安装、零注册，打开网页即可游戏 |

## 2. 功能清单

### 2.1 游戏循环

| 编号 | 功能 | 说明 |
|------|------|------|
| F-01 | 开始界面 | 展示游戏标题、操作提示、"开始游戏"按钮；首次进入自动展示 |
| F-02 | 蛇的移动 | 蛇以固定间隔自动向当前方向移动一格；初始方向向右 |
| F-03 | 食物生成 | 随机在空白格子生成一个食物；同时场上仅存在 1 个食物 |
| F-04 | 吃食物 | 蛇头进入食物格子 → 蛇身增长 1 节、得分 +10、立即生成新食物 |
| F-05 | 碰撞检测-边界 | 蛇头触碰画布边界 → 游戏结束 |
| F-06 | 碰撞检测-自身 | 蛇头触碰蛇身任意一节 → 游戏结束 |
| F-07 | 结束界面 | 显示本局得分、历史最高分、"重新开始"按钮 |

### 2.2 计分

| 编号 | 功能 | 说明 |
|------|------|------|
| F-08 | 实时计分 | 游戏进行中，画面顶部/侧边实时显示当前得分 |
| F-09 | 得分规则 | 每吃一个食物 +10 分；无其他加分项 |

### 2.3 暂停 / 继续

| 编号 | 功能 | 说明 |
|------|------|------|
| F-10 | 暂停 | 按空格键或点击"暂停"按钮 → 蛇停止移动，画面叠加"已暂停"遮罩 |
| F-11 | 继续 | 暂停状态下再次按空格或点击"继续"按钮 → 恢复移动 |

### 2.4 重新开始

| 编号 | 功能 | 说明 |
|------|------|------|
| F-12 | 重开入口 | 结束界面提供"重新开始"按钮；游戏中暂停遮罩也提供"重新开始"按钮 |
| F-13 | 重开行为 | 重置蛇位置/方向/长度、清零当前得分、重新生成食物，回到游戏进行状态 |

### 2.5 最高分记录

| 编号 | 功能 | 说明 |
|------|------|------|
| F-14 | 本地持久化 | 使用 localStorage 存储历史最高分，关闭浏览器后仍保留 |
| F-15 | 最高分展示 | 开始界面、结束界面、游戏中 HUD 均展示历史最高分 |
| F-16 | 更新判定 | 本局得分 > 历史最高分时，自动更新并给予"新纪录！"提示（2 秒后自动消失） |

## 3. 操作方式

| 输入设备 | 操作 | 对应行为 |
|----------|------|----------|
| 键盘方向键 ↑ ↓ ← → | 改变蛇移动方向 | 不允许 180° 反向（如正在向右时按←无效） |
| 键盘 W/A/S/D | 同方向键 | 同上 |
| 空格键 | 暂停 / 继续 | 切换暂停状态 |
| 移动端触屏滑动 | 改变蛇移动方向 | 滑动方向映射为上下左右，同样禁止 180° 反向 |
| 按钮（鼠标/触屏点击） | 开始 / 暂停 / 继续 / 重新开始 | 对应功能按钮 |

## 4. 验收标准

> 勾选格式：[ ] 未通过 / [x] 已通过

- [ ] **AC-01**：打开 HTML 文件后 3 秒内渲染出开始界面，无 JS 报错
- [ ] **AC-02**：点击"开始游戏"后蛇自动向右移动，按方向键可正确转向且不会 180° 反向
- [ ] **AC-03**：蛇吃到食物后身体增长 1 节，得分 +10，画面实时更新分数
- [ ] **AC-04**：蛇撞墙或撞自身后进入结束界面，显示本局得分与历史最高分
- [ ] **AC-05**：按空格键可暂停/继续，暂停时蛇完全静止，画面有"已暂停"遮罩
- [ ] **AC-06**：点击"重新开始"后蛇、得分、食物全部重置，游戏立即重新开始
- [ ] **AC-07**：最高分通过 localStorage 持久化，关闭标签页后重新打开仍可读取
- [ ] **AC-08**：移动端浏览器可通过触屏滑动操控蛇的方向，游戏区域自适应屏幕宽度
- [ ] **AC-09**：单局游戏无内存泄漏（连续游玩 50 局后页面帧率 ≥ 30fps）

## 5. 非目标（明确不做）

| 编号 | 不做事项 | 原因 |
|------|----------|------|
| X-01 | 多人对战 / 排行榜服务器 | 本版本为单机休闲，不涉及后端 |
| X-02 | 关卡系统 / 难度递增 | 保持规则简单，后续版本再评估 |
| X-03 | 皮肤 / 道具 / 内购 | 无商业化需求 |
| X-04 | 音效与背景音乐 | 首版聚焦核心玩法，音效作为增强项后续迭代 |
| X-05 | 穿墙模式（边界穿越） | 默认撞墙死亡，穿墙作为可选模式留待 v2 |
| X-06 | 加速机制 | 蛇移动速度固定，不做随分数加速 |
