## 一、产品定位与目标用户

### 1.1 产品定位

AgentRater 是一个面向 AI 智能体应用的**点评与发现平台**。用户可以浏览、搜索、筛选各类 AI Agent，查看综合评分与用户评价，为心仪的 Agent 点赞、收藏和撰写评价——就像用大众点评找餐厅一样，用 AgentRater 找到最适合自己的 AI 智能体。

**核心差异化**：业务对象不是商铺或商品，而是 **AI 智能体应用**（编程助手、客服机器人、数据分析 Agent、绘画 Agent、写作 Agent、翻译 Agent 等）。平台聚焦"Agent 能力 × 用户口碑"的双轮驱动，帮助用户在 Agent 爆发时代高效决策。

### 1.2 目标用户

| 用户群 | 画像 | 核心诉求 |
|--------|------|----------|
| **开发者 / 技术人员** | 需要集成 Agent 到工作流，关注 API 能力、稳定性、性价比 | 快速对比同类 Agent 的评分与真实评价，筛选最优选 |
| **企业决策者 / 采购** | 为团队选型，关注安全合规、服务等级、部署方式 | 一站式浏览分类 Agent，参考综合评分做采购决策 |
| **普通 AI 用户** | 日常使用 Agent 提升效率，关注易用性、输出质量 | 发现好用的 Agent，看评价避坑，收藏常用 Agent |
| **Agent 创作者 / 团队** | 希望自己的 Agent 被发现和认可 | 获得曝光与真实用户反馈，持续迭代优化 |

### 1.3 产品目标

1. **发现**：让用户 30 秒内找到目标分类下的高分 Agent  
2. **决策**：通过评分分布 + 真实评价，降低选型成本  
3. **互动**：点赞、收藏、评价形成社区氛围，驱动内容飞轮

## 二-G! 二、页面清单

### 2.1 首页（Agent 探索页）

> 路由：`/` 或 `/index.html`

| 区域 | 说明 |
|------|------|
| **顶部导航栏** | Logo「AgentRater」+ 搜索框 + 收藏入口（显示收藏数量角标） |
| **分类筛选栏** | 横向 Tab：全部 / 编程助手 / 客服机器人 / 数据/数据分析 / 绘画创作 / 写作辅助 / 翻译语言 / 其他 |
Agen | **$分类$ 点击后筛选对应分类的 Agent 卡片 |
| **排序控制栏** |( 排序按钮组：综合评分↓ / 评价数↓ / 默认（按 id 排序） |
| **Agent 卡片网格** | 响应式网格（桌面 4 列 / 平板 3 列 / 手机 2 列），每张卡片展示：缩略图、名称、分类标签、综合评分（星级）、评价数、一句话简介、收藏❤按钮 |
| **空状态** | 搜索/筛选无结果时展示友好提示「未找到匹配的 Agent，试试其他关键词？」 |

### 2.2 详情页（Agent 详情 + 评价页）

> 路由：`/detail.html?id={agentId}`

| 区域 | 说明 |
|------|------|
| **返回导航** | ← 返回首页 面包屑 |
| **Agent 信息卡** | 大图 + 名称 + 分类 + 标签组 + 综合评分（大号星级）+ 评价数 + 一句话简介 + 收藏按钮 |
| **评分分布图** | 5→1 星的柱状分布，每行显示：星数 + 横条（宽度按占比）+ 百分C比 + 人数 |
| **评价列表** | 每条评价：用户名 + 星级 + 评价内容 + 时间 + 👍点赞按钮 + 点赞数 |
| **写评价入口** | 底部「写评价」按钮 → 弹出模态框（选星级 + 输入内容 + 提交），提交后即时追加到评价列表顶部 |

## 三、Agent 数据模型

### 3.1 字段定义

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `id` | `string` | ✅ | 唯一标识，格式 `agent_XX` | `"agent_01"` |
| `name` | `string` | ✅ | Agent 名称，≤20 字 | `"CodePilot 编程助手"` |
| `category` | `string` | ✅ | 分类枚举值 | `"编程助手"` |
| `rating` | `number` | ✅ | 综合评分，1+1.0~5.0，保留一位小数 | `4.7` |
| `reviewCount` | `number` | ✅ | 评价总数，≥0 | `328` |
| `tags` | `string[]` | ✅ | 标签数组，每项 ≤8 字，共 ≤5 个 | `["代码生成","Debug","多语言"]` |
| `summary` | `string` | ✅ | 一句话简介，≤40 字 | `"基于大模型的智能编程辅助Agent，支持代码生成与调试"` |
| `image` | `string` | ✅ | 图片文件名，对应 images/ 目录 | `"shop_01.jpg"` |

### 3.2 分类枚举

```
编程助手 | 客服机器人 | 数据分析 | 绘画创作 | 写作辅助 | 翻译语言 | 其他
```

### 3.3 图片素材映射

`images/` 目录已有 20 张卡片图（`shop_01.jpg` ~ `shop_20.jpg`，800×600），按 `id` 顺序映射：

| Agent id | image |
|----------|-------|
| agent_01 | shop_01.jpg |
| agent_02 | shop_02.jpg |
| … | … |
| agent_20 | shop_20.jpg |

> 若 Agent 数量 > 20，后续循环复用（agent_21 → shop_01.jpg）。

### 3.4 示+充数据约定

- 首屏至少 **20 条** Agent 数据，覆盖全部 7 个分类  
- 每条 Agent 至少 **3 条** 评价数据，含不同星级  
- 评分分布由评价数据实时计算得出

## 四、交互功能清单

### 4.1 搜索

| 编号 | 功能 | 规则 |
|------|------|------|
| F-01 | 关键词搜索 | 输入关键词后实时过滤（防抖 300ms），匹配字段：`name`、`summary`、`tags`（任一包含即命中，不区分大小写） |
| F-02 | 搜索清空 | 搜索框右侧 ✕ 按钮清空关键词，恢复全量展示 |
| F-03 | 搜索+筛选联动 | 搜索与分类筛选同时生效，取交集 |

### 4.2 分类筛选

| 编号 | 功能 | 规则 |
|------|------|------|
| F-04 | 分类 Tab 切换 | 点击分类 Tab，卡片网格仅展示该分类 Agent；「全部」Tab 展示所有 |
| F-05 | 选中态高亮 | 当前选中 Tab 有明确视觉区分（底色/下划线） |

### 4.3 排序

| 编号 | 功能 | 规则 |
|------|------|------|
| F-06 | 综合评分降序 | 按 `rating` 从高到低排列 |
| F-07 | 评价数降序 | 按 `reviewCount` 从高到低排列 |
| F-08 | 默认排序 | 按 `id` 升序（原始顺序） |
| F-09 | 排序互斥 | 同一时刻仅一种排序生效，选中态高亮 |

### 4.4 评价互动

| 编号 | 功能 | 规则 |
|------|------|------|
| F-10 | 评价点赞 | 点击 👍 按钮点赞数 +1，再次点击取消（toggle），状态存 localStorage |
| F-11 | 写评价 | 模态框选 1~5 星 + 输入评价内容（≥5 字），提交后追加到评价列表顶部，该 Agent 的 `reviewCount` +1，`rating` 重新计算 |
| F-12 | 评价即时可见 | 新评价无需刷新页面即可在列表中看到 |

### 4.5 收藏

| 编号 | 功能 | 规则 |
|------|------|------|
| F-13 | 收藏 Agent | 首页卡片 / 详情页点击 ❤ 按钮切换收藏状态，数据存 localStorage（key: `agentrater_favorites`，值: id 数组） |
| F-14 | 收藏角标 | 导航栏收藏图标右上角显示已收藏数量 |
| F-15 | 收藏页/筛选 | 点击收藏入口可筛选出仅已收藏的 Agent（或在首页增加「仅看收藏」开关） |

### 4.6 页面跳转

| 编号 | 功能 | 规则 |
|------|------|------|
| F-16 | 卡片→详情 | 点击 Agent 卡片跳转至详情页，URL 携带 `id` 参数 |
| F-17 | 详情→首页 | 详情页「返回」按钮回到首页，保留之前的搜索/筛选/排序状态（通过 URL query 或 sessionStorage） |

## 五、非功能要求

| 维度 | 要求 |
|------|------|
| **性能** | 首屏渲染 < 1s（本地静态资源）；搜索过滤 < 100ms |
| **兼容性** | Chrome / Edge / Firefox / Safari 最新 2 个大版本；移动端适配（响应式） |
| **数据持久化** | 收藏、点赞状态通过 localStorage 持久化，刷新页面后状态保留 |
| **无障碍** | 图片有 alt 文本；星级评分有 aria-label；按钮可键盘聚焦 |

## 六、验收标准（≥ 8 条）

| # | 验收标准 | 优先级 |
|---|----------|--------|
| AC-01 | **首页展示 20 张 Agent 卡片**，每张卡片完整显示：缩略图、名称、分类、星级评分、评价数、一句话简介、收藏按钮 | P0 |
| AC-02 | **搜索功能**：输入关键词后卡片实时过滤，匹配名称/简介/标签；清空关键词恢复全量；无结果时展示空状态提示 | P0 |
| AC-03 | **分类筛选**：点击分类 Tab 仅展示对应分类 Agent，点击「全部」恢复；选中 Tab 有高亮态 | P0 |
| AC-04 | **评分排序**：切换「综合评分↓」后卡片按评分从高到低重排；切换「评价数↓」按评价数降序；切换「默认」恢复原始顺序；排序互斥且高亮 | P0 |
| AC-05 | **详情页完整展示**：Agent 大图、名称、分类、标签、评分、评价数、简介、收藏按钮均正确渲染 | P0 |
| AC-06 | **评分分布图**：5→1 星柱状分布正确显示，各星级人数之和 = 总评价数，百分比计算正确 | P0 |
| AC-07 | **评价列表**：展示该 Agent 全部评价，每条含用户名、星级、内容、时间、点赞按钮及点赞数 | P0 |
| AC-08 | **评价点赞 toggle**：点击 👍 点赞数 +1 且按钮变为已赞态；再次点击取消，点赞数 -1；刷新页面后点赞状态保留（localStorage） | P0 |
| AC-09 | **写评价并即时可见**：点击「写评价」弹出模态框，选星级 + 输入内容后提交，新评价出现在列表顶部，该 Agent 评价数 +1、评分重算 | P0 |
| AC-10 | **收藏功能**：点击 ❤ 切换收藏状态，导航栏收藏角标实时更新；刷新后收藏状态保留（localStorage） | P0 |
| AC-11 | **卡片→详情跳转**：点击卡片跳转至 `detail.html?id=xxx`，详情页数据与卡片一致 | P0 |
| AC-12 | **详情→首页返回**：点击返回按钮回到首页，之前的搜索关键词、分类筛选、排序状态保留 | P1 |

## 七、信息架构总览

```
AgentRater
├── 首页 (/)
│   ├── 顶部导航（Logo + 搜索框 + 收藏入口）
│   ├── 分类筛选栏（7 个 Tab）
│   ├── 排序控制栏（3 种排序）
│   └── Agent 卡片网格（20 张）
│       └── 卡片 → 详情页
└── 详情页 (/detail.html?id=xxx)
    ├── 返回导航
    ├── Agent 信息卡
    ├── 评分分布图
    ├── 评价列表（含点赞）
    └── 写评价模态框
```
