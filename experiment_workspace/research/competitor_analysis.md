## 二、企业官网导航 / 首屏 / 服务页最佳实践

### 2.1 导航最佳实践

| 实践项 | 说明 |
|--------|------|
| 项数控制 | 主导航 4-6 项为黄金区间；超过 7 项应使用二级下拉或折叠菜单 |
| 移动端 | 汉堡菜单 + 全屏滑出面板，保留品牌Logo可见 |
| 当前页标识 | 当前页导航项高亮（下划线/色块/字重变化） |
| 固定导航 | 滚动时导航固定顶部（sticky），滚动超过首屏后可收缩为精简条 |
| 页脚冗余导航 | 页脚重复全部一级+二级链接，兼顾SEO与用户兜底查找 |
| CTA外置 | "联系我们"或"预约咨询"按钮可从导航中突出（不同底色/边框） |

### 2.2 首屏最佳实践

| 实践项 | 说明 |
|--------|------|
| 视觉层级 | 背景（图/视频）→ 品牌标语（H1）→ 副标语（H2）→ CTA按钮，四层从后到前 |
| 标语原则 | 一句话讲清"我们是谁+做什么"，不超过15字（中文）；避免空泛口号 |
| CTA | 首屏必须有且仅有一个主CTA（实心按钮）+ 可选次CTA（线框按钮） |
| 首屏高度 | 桌面端100vh全屏；移动端最小80vh，避免内容被键盘遮挡 |
| 加载体验 | 首屏图/视频需懒加载+低分辨率占位；文字先于媒体渲染 |
| 无障碍 | 背景图上文字需有半透明遮罩层确保对比度 ≥ 4.5:1 |

### 2.3 服务页最佳实践

| 实践项 | 说明 |
|--------|------|
| 结构 | 总览区（一句话定位）→ 服务卡片网格 → 各服务详情区（可展开/跳转） |
| 卡片设计 | 图标/插图 + 服务名称（H3）+ 一句话简介 + "了解更多"链接 |
| 详情呈现 | 图文左右交替布局（奇偶行反转），避免纯文字墙 |
| 数据可视化 | 核心参数用数字高亮+单位标注（如"LEO运载力 500kg"），比表格更直观 |
| 应用场景 | 每项服务配1-2个典型应用场景，帮助客户对号入座 |
| 信任元素 | 穿插客户Logo、合作机构、成功案例数据 |

## 三、本项目设计与文案建议

### 建议 1：首屏采用"深空场景 + 一句定位语"的沉浸式方案

- **依据**：SpaceX、Rocket Lab、蓝箭均采用全屏视觉+标语方案，行业已成标配。
- **具体方案**：首屏背景使用深空星场图（主色 #0B2545 氛围），居中放置品牌名"星舟科技"+ 定位语（如"让太空触手可及"）+ 主CTA"了解我们的服务"。滚动后进入内容区。
- **移动端适配**：背景图改为静态深空图（省流量+性能），文字/CTA垂直居中，字号适当放大。

### 建议 2：服务页按三大业务线分板块，采用"图标卡片 + 详情展开"两层结构

- **依据**：中科宇航的Tab式、蓝箭的分板块式均有效；星舟业务线明确（卫星服务/火箭测运控/数据应用），适合卡片式总览。
- **具体方案**：服务页顶部三列卡片（每列一个业务线），每卡片含自定义SVG图标+业务名+一句话简介。点击"了解更多"平滑滚动至下方对应详情区。详情区采用图文左右交替布局，配核心参数高亮条。
- **文案方向**：每项服务简介控制在25字以内，突出"做什么+为谁做"；详情区首句必须是业务价值陈述而非技术描述。

### 建议 3：配色严格执行"深空蓝主色 + 星辉金强调 + 高留白"，杜绝红紫色调

- **依据**：客户品牌要求明确；对标Blue Origin/中科宇航的深蓝+金方案验证了该配色在航天领域的专业感与辨识度。
- **具体方案**：
  - 主色 `#0B2545`：导航背景、页脚背景、首屏背景、章节分隔条
  - 强调色 `#D4AF37`：CTA按钮、图标描边、参数数字、链接hover态
  - 正文色 `#E8E8E8`（深色背景上）/ `#1A1A1A`（浅色背景上）
  - 留白：章节间距 ≥ 80px（桌面）/ 48px（移动）；卡片内padding ≥ 32px
  - **红线**：全局CSS变量中不引入任何红/紫色相（hue 330-30）作为装饰色

### 建议 4：文案全程嵌入"商业航天"语境，避免通用企业站套话

- **依据**：验收标准③要求文案必须体现商业航天业务；对标站点均使用行业术语建立专业信任。
- **具体方案**：
  - 首页标语：体现"航天+商业"双重属性，如"以商业航天赋能新太空经济"
  - 关于我们：突出团队航天背景、资质认证、发射/在轨服务记录
  - 服务页：每项业务使用行业术语（如"多轨道部署""在轨测运控""遥感数据下行"），避免写成"我们提供优质服务"
  - 新闻动态：标题需含具体事件（如"星舟完成第X次轨道交付"），不用"公司动态"等泛词
  - 联系我们：表单提示语用航天场景（如"告诉我们您的太空需求"），不用"请留言"

### 建议 5：导航与页脚采用"5+1"结构，联系入口全局突出

- **依据**：项目要求五页（首页/服务/关于我们/新闻动态/联系我们），对标蓝箭/中科宇航的5-6项导航；联系表单是核心转化入口。
- **具体方案**：
  - 主导航五项：首页 | 服务 | 关于我们 | 新闻动态 | 联系我们
  - "联系我们"在导航中用星辉金边框按钮样式突出（区别于其他文字链接）
  - 页脚四列布局：①品牌Logo+一句话介绍 ②快捷导航（重复五项）③业务线快捷入口 ④联系方式+社交媒体图标
  - 移动端：汉堡菜单全屏滑出，"联系我们"固定在滑出面板底部作为CTA按钮
